## 1. 배치

```
        ┌──────────────────────────────────────────────┐
        │  200 × 300 mm 브레드보드 (평면도)             │
        │                                              │
        │            PD ▲                              │
        │               │  (1단계 미사용)               │
        │      PSD ◀────╳ BS                           │
        │               ▲                              │
        │               │  100 mm                      │
        │   TX ────────▶╱ FSM  (미러 45°)              │
        │      100 mm                                  │
        └──────────────────────────────────────────────┘

        L = FSM → BS → PSD = 100 + 100 = 200 mm   (실측 필요)
```

- TX 레이저 → **FSM** → BS → { PSD (피드백), PD (최종 수신) }
- **FSM 이 BS 상류에 있는 것이 핵심이다.** 조향이 두 갈래에 모두 나타나야 PSD 피드백으로
  폐루프가 성립한다. FSM 을 BS 하류에 두면 FSM 을 움직여도 PSD 스팟이 안 움직여
  `J ≡ 0` 이 되고 제어가 원천적으로 불가능하다 (검토 중 기각된 배치).
- 1단계에서는 PD 를 쓰지 않는다. PSD 만으로 "FSM 으로 제어가 되는가"를 확인한다.

## 2. 미러 각도: 45°

빔을 **90° 꺾으려면** 미러면이 입사빔·반사빔과 각각 **45°** 를 이뤄야 한다.
판단 기준은 하나다 — **미러 법선이 입사빔과 반사빔을 이등분하면 맞다.**

수직 입사(0°)로 놓으면 빔이 왔던 길로 그대로 되돌아가므로 조향이 성립하지 않는다.

### 이 45° 가 `u = 0` 이어야 한다

FSM 의 전기적 영점(`optoMDC` XY 정규화 0, 0)을 기계적 45° 에 맞춰 마운트하고,
±가동범위는 그 주변의 보정 여유로 쓴다. 기울어진 상태를 영점으로 잡으면 한쪽 가동범위를
그만큼 못 쓴다.

---

## 3. 45° 에서 두 축의 이득이 다르다

"미러를 δ 기울이면 빔이 2δ 꺾인다"는 **한 축에서만** 맞다.
비스듬히 입사하면 나머지 한 축은 `cos α` 만큼 손해를 본다.

| 회전축 | 빔이 움직이는 방향 | 빔 편향각 |
|---|---|---|
| 입사면에 **수직**인 축 | 보드 평면 **안**에서 | **2δ** |
| 입사면 **안**에 있는 축 | 보드 평면 **밖**으로 | **2δ·cos α** |

45° 입사에서 `cos 45° = 0.707` 이므로 두 축 감도가 약 **30 % 차이** 난다.

### 유도

반사식과 미소 회전:

```
d_out = d_in − 2 (d_in · n̂) n̂
미러가 축 â (미러면 안) 둘레로 δ 회전 →  δn̂ = δ (â × n̂)
δd_out = −2 [ (d_in · δn̂) n̂ + (d_in · n̂) δn̂ ]
```

90° 접기를 구체적으로 넣어 검산하면 (d_in = +x, d_out = +y, n̂ = (−1, 1, 0)/√2):

**축 A — 입사면에 수직 (â = ẑ)**

```
δn̂     = δ (ẑ × n̂) = δ (−1, −1, 0)/√2
δd_out = −2 [ (−δ/√2)(−1,1,0)/√2 + (−1/√2)·δ(−1,−1,0)/√2 ]
       = −2 [ (δ/2, −δ/2, 0) + (δ/2, δ/2, 0) ]
       = (−2δ, 0, 0)              →  |δd_out| = 2δ
```

**축 B — 입사면 안, 미러면 안 (â = (1,1,0)/√2)**

```
â × n̂  = ẑ        →  δn̂ = δ ẑ
d_in · δn̂ = 0
δd_out = −2 [ 0 + (−1/√2)(0,0,δ) ] = (0, 0, √2 δ)   →  |δd_out| = √2 δ = 2δ·cos45°
```

일반형: 입사각 α 에서 in-plane 이득 `2`, out-of-plane 이득 `2 cos α`.

### 이건 고칠 문제가 아니라 예상해야 할 값이다

비대칭은 `fsm_calibrate.py` 가 실측하는 `J` 안에 그대로 들어가고, 제어는 `J⁻¹` 를 쓰므로
**자동으로 보상된다.** 축마다 게인을 따로 잡을 필요가 없다.

다만 `cond(J)` 가 1.0 이 아니라 **1.4 근처**로 나오는 것이 정상이라는 걸 알고 있어야,
그 값을 보고 배치를 의심하지 않는다.

## 4. 접는 각도를 바꾸면

```
빔을 꺾는 각 = 180° − 2α        out-of-plane 이득 = 2 cos α        cond(J) = 1 / cos α
```

| 빔을 꺾는 각 | 입사각 α | in-plane | out-of-plane | cond(J) |
|---|---|---|---|---|
| 60° | 60° | 2.00 | 1.00 | 2.00 |
| **90°** | **45°** | **2.00** | **1.41** | **1.41** |
| 120° | 30° | 2.00 | 1.73 | 1.15 |
| 135° | 22.5° | 2.00 | 1.85 | 1.08 |

얕게 입사할수록 두 축이 대칭에 가까워지지만, 빔 경로가 길어지고 부품 간섭이 늘어난다.
직사각형 보드에서는 **90° 접기**가 현실적인 선택이다.

## 5. 마운팅 체크리스트

- [ ] 미러면을 입사빔·반사빔과 각각 45°. **법선이 두 빔을 이등분**하면 맞다.
- [ ] **이 45° 가 `u = 0`** 이 되도록 FSM 전기적 영점을 기계적 45° 에 맞춘다.
- [ ] `u = 0` 에서 빔이 미러 **중심**에 오도록 높이·좌우를 맞춘다.
      가장자리에 맞추면 한쪽 가동범위를 못 쓴다.
- [ ] **클로킹**: FSM 채널 축 하나를 보드면과 나란하게. 그래야 `J` 가 거의 대각이 되고
      축간 커플링이 작다. 비스듬히 물리면 off-diagonal 이 커진다 (제어는 되지만 튜닝이 까다롭다).
- [ ] **유효 구경**: 45° 입사에서 빔 자국이 한 방향으로 `√2` 배 늘어난다. 미러 구경이 `D` 면
      그 방향으로 실질 `0.71 D`. 빔 지름이 여유 있게 들어가는지 확인.
      (MR-15-30 실제 구경은 미확인 — 데이터시트 확인 필요.)
- [ ] **`L` 실측**: FSM → BS → PSD 접힌 경로 전체 길이를 자로 잰다.
- [ ] `python fsm_jog.py` 로 확인. 축 독립성 > 0.9, `cond(J)` ≈ 1.4 면 의도대로 된 것이다.

## 6. L 이 결정하는 값

`L` 은 **접힌 경로 전체 길이**다 (FSM→BS 와 BS→PSD 의 합). BS 는 경로를 꺾을 뿐이라
길이에 그대로 더해진다.

| 항목 | 계산 | L = 200 mm |
|---|---|---|
| `L_M` (코드 입력) | 실측, 미터 단위 | `0.200` |
| PSD 가 담는 각도 | `PSD_LIMIT / L` | ±25 mrad |
| 각도 분해능 | `PSD 노이즈 2µm / L` | ≈ 10 µrad |
| blind 스윕 Y 허용 | `PSD_LIMIT / L` | ±25 mrad |

L 별 비교:

| L | PSD 가 담는 각도 | 각도 분해능 |
|---|---|---|
| 100 mm | ±50 mrad | 20 µrad |
| 150 mm | ±33 mrad | 13 µrad |
| 200 mm | ±25 mrad | 10 µrad |
| 250 mm | ±20 mrad | 8 µrad |

**트레이드오프.** 레버암이 짧으면 담는 각도는 넓어지고 분해능은 나빠진다.
폐기된 4 m 가정에서는 Y 허용이 ±1.25 mrad 로 빡빡했는데, 200 mm 에서는 ±25 mrad 로 넉넉하다.
대신 분해능이 2.5 µrad → 10 µrad 로 나빠진다. 짧은 레버암의 정직한 대가다.

쓰므로 `L` 과 무관하게 동작한다** — `fsm_PID.py` 까지는 `L_M` 이 틀려도 정상이다.
